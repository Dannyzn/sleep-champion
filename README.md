# 熬夜冠军 Sleep Champion

一个记录睡眠状态的社交化平台，通过游戏化机制让用户在"熬夜冠军"和"早睡冠军"两个极端之间形成有趣的互动。

## 项目状态

🚧 开发中 - MVP阶段

## 核心功能

- 睡眠打卡记录
- 实时排行榜（熬夜冠军 & 早睡冠军）
- 个人睡眠数据统计
- 社交互动

## 技术栈

- Next.js 14
- React 18
- Tailwind CSS
- PostgreSQL (Supabase)
- Vercel
