# 熬夜冠军 - 项目文档

## 项目概述

一个记录用户睡眠状态的社交化平台，通过游戏化机制让用户在"熬夜冠军"和"早睡冠军"两个极端之间形成有趣的互动。

## 核心理念

- 让睡眠记录变得有趣
- 双榜机制：熬夜和早睡都是冠军
- 社交化的睡眠数据分享
- 帮助用户了解自己的睡眠习惯
