# UI/UX 设计指南

## 1. 设计理念

**双主题概念**:
- 熬夜模式：深色、神秘、夜晚氛围
- 早睡模式：明亮、温暖、清晨氛围

---

## 2. 色彩系统

### 熬夜主题
- 主色：`#1a1a2e` (深蓝黑)
- 辅色：`#16213e` (深蓝)
- 强调色：`#0f3460` (蓝紫)
- 高亮：`#e94560` (粉红)

### 早睡主题
- 主色：`#fff5e6` (暖白)
- 辅色：`#ffe4b5` (浅橙)
- 强调色：`#ffa500` (橙色)
- 高亮：`#ff6b6b` (珊瑚红)

---

## 3. 核心页面

### 首页
- 顶部：当前在线人数
- 中间：快速打卡按钮
- 底部：双排行榜切换

### 排行榜
- 卡片式设计
- 前3名特殊样式
- 显示头像、昵称、睡眠时间

### 个人主页
- 顶部：统计卡片
- 中间：日历视图
- 底部：历史记录列表

---

## 4. 交互设计

### 打卡动效
- 点击按钮 → 涟漪效果
- 提交成功 → 庆祝动画
- 显示排名变化

### 排行榜
- 下拉刷新
- 无限滚动
- 实时更新提示
